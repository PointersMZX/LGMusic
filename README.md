# 甘露音乐（LG Music）

甘露音乐是一款免费开源的聚合音乐播放器，由极星（Pointers）开发，提供 Windows 端与 Android 端。

## 功能

- **多音源聚合搜索**：综合渠道固定排在最前，另有 星记（酷我）/ 星芸（网易）/ 星腾（QQ）/ 星犬（酷狗）/ 星谷（咪咕） 5 条渠道，支持按歌曲、歌手、专辑等分类搜索
- **本地音乐**：添加本地目录自动扫描（支持子文件夹，mp3/flac/ogg/oga/wav/m4a），4 种默认排序 + 自定义拖动排序、按歌名实时搜索、多选管理（删除仅从列表移除，保留本地文件）
- **4 套主题**：紫金黑（默认，液态玻璃视觉：磨砂玻璃 + 折射 + 七彩色散 + 金色边缘流光）/ 自定义（支持玻璃开关与取色）/ 纯白 / 纯黑
- **歌词**：随歌曲加载 .lrc 歌词；移动端支持锁屏歌词与浮窗歌词，无歌词时统一显示应用标识
- **自定义音源**：可导入自己的在线音源
- **自动更新**：Windows 端应用内版本检查

## 下载与安装

- **官网直装**（推荐）：[lgmusic.pointers-box.cc.cd](https://lgmusic.pointers-box.cc.cd) 下载页
  - Windows：安装版与便携版（7z 压缩包），分普通版与 Win7 兼容版（Win7 兼容版文件名带 `win7` 标识）
  - Android：APK（universal 通用包 + 4 个分架构包，大多数设备装 universal 即可）
- **其他渠道**：GitHub / Gitee / 蓝奏云，链接见官网下载页

> 品牌更名说明：Android 端旧版本需先卸载再安装新版；Windows 端更新后设置将重置（启用新数据目录）。

## 更新

- Windows 端：应用内自动检查更新
- Android 端：到官网下载页获取新版本 APK
